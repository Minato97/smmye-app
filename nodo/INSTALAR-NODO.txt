INSTALAR UN NODO SMMyE DESDE LA TERMINAL DE LA RASPBERRY PI
===========================================================
Todo se hace con UN comando. No hace falta abrir el panel en la Pi.

ANTES DE EMPEZAR
  - Sensores conectados y funcionando (como con Estacion02.py).
  - Estacion02.py: si sigue corriendo o en el crontab, el instalador lo muestra y pregunta si lo detiene y lo quita
    del arranque (comenta su línea del crontab y guarda un respaldo).
  - La Raspberry con internet.
  - Usuario y contraseña de un ADMINISTRADOR del panel SMMyE.

1) CORRER EL SCRIPT
   Abre una terminal en la Pi y pega:

     curl -fsSL https://smmye-app.pages.dev/i -o i.sh && bash i.sh

   (Todos los comandos con botón Copiar: https://smmye-app.pages.dev/guia
    Versión larga, directo a la API:
     curl -fsSL https://procurer-glaring-huddling.ngrok-free.dev/smmye/api/nodo/instalar -o instalar-nodo.sh && bash instalar-nodo.sh )

2) CONTESTAR LO QUE PIDE
   - Usuario administrador del panel
   - Contraseña                          (no se ve al escribirla y no se guarda)
   - Nombre sugerido para el nodo        (Enter para omitir; se puede poner al aprobar)
   - Vigencia del instalador en horas    (Enter = 24)
   Si ya existía ~/smmye-nodo, primero pregunta si se reemplaza.

   El script genera el instalador, lo descomprime en ~/smmye-nodo y muestra la URL de la API
   y cuántos sensores se van a revisar.

3) "¿Correr el instalador ahora?"  ->  Enter (sí)
   El instalador revisa la conexión con el panel y luego muestra una TABLA DE SENSORES:
   cuáles respondieron, por qué pin/puerto y qué leyeron.
     - Gira el anemómetro y mueve el balancín del pluviómetro mientras prueba, para confirmarlos.
     - Si uno que está conectado sale "NO RESPONDIÓ": revisa su cableado y pulsa  r  para volver a probar.
     - Enter  = instalar con lo que salió
     - q      = salir sin instalar nada
   Cada sensor tiene hasta 30 s para responder.

4) APROBAR EL NODO EN EL PANEL (un administrador)
   Campana de notificaciones -> solicitud del nodo nuevo (por su MAC) -> nombre y área.
   En el checklist ya vienen marcados los que respondieron; los "No respondió" vienen sin marcar.
   Ajusta lo que haga falta y pulsa Aprobar.

5) COMPROBAR
     journalctl -u smmye-agente -f          (Ctrl+C para salir)
   Debe decir "Nodo aprobado: clave recibida", "Sesión iniciada" y "Lote guardado".
   La primera muestra llega ~15 segundos después de aprobar; luego, una cada 5 minutos.

SI ALGO FALLA
  "Usuario o contraseña incorrectos"          revisa los datos del administrador.
  "no es administrador"                       ese usuario no puede generar instaladores.
  "Demasiados intentos"                       espera 15 minutos.
  "No hay conexión con la API"                revisa el internet de la Raspberry.
  "Encontré el programa anterior"             contesta Enter: detiene Estacion02.py y lo quita del crontab.
  "La MAC ... YA es una estación"             ese nodo ya está dado de alta en el panel.
  Un sensor "No respondió" después de aprobar: arréglalo y reinicia el agente; se agrega solo
  (sudo systemctl restart smmye-agente).

SI SALEN LETRAS O SÍMBOLOS RAROS (Â°C, Ã¡, �)
  La Raspberry está en latin-1. Corre los dos y reinicia (sudo reboot); "locale charmap" debe decir UTF-8:
    sudo sed -i 's/^# *es_MX.UTF-8 UTF-8/es_MX.UTF-8 UTF-8/' /etc/locale.gen && sudo locale-gen && sudo update-locale LANG=es_MX.UTF-8 LANGUAGE=es_MX:es LC_ALL=es_MX.UTF-8
    sudo sed -i 's/^CHARMAP=.*/CHARMAP="UTF-8"/' /etc/default/console-setup && sudo setupcon
  Si aún salen �: es la fuente de la consola de texto. El monitor usa caracteres simples solo; forzarlo: smmye-monitor --ascii
  (Con botón Copiar: https://smmye-app.pages.dev/smmye-app/docs/comandos#letras )

ÚTILES
  smmye-monitor                                     cada sensor con su última medida, en vivo (Ctrl+C para salir)
  sudo systemctl stop smmye-agente && (cd /opt/smmye && python3 smmye_agente.py --revisar); sudo systemctl start smmye-agente
                                                    vuelve a mostrar la tabla de sensores (el agente se detiene
                                                    mientras tanto porque ocupa los puertos)
  sudo systemctl restart smmye-agente               reiniciar el agente
  sudo systemctl stop smmye-agente                  detenerlo (p. ej. para volver a Estacion02.py)
