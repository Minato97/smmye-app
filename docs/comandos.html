Comandos para instalar un nodo

Copia cada comando con su botón y pégalo en la terminal de la Raspberry Pi (en la terminal se pega con Ctrl+Shift+V). Los pasos completos, con ejemplos de cada pantalla, están en la guía en PDF.

⬇ Descargar la guía en PDF

1Comprobar la conexión con la API

Debe decir API: HTTP 200. 000 = la Pi no tiene internet; 404 = el servidor no tiene la versión nueva.

curl -sSL -m 20 -o /dev/null -w 'API: HTTP %{http_code}\n' https://smmye-app.pages.dev/i

2Descargar e instalar (un solo comando)

Pide usuario y contraseña de un administrador del panel, genera el instalador, lo descomprime en ~/smmye-nodo y lo corre. Si Estacion02.py sigue corriendo, te pregunta si lo detiene.

curl -fsSL https://smmye-app.pages.dev/i -o i.sh && bash i.sh

Versión larga (misma acción, directo a la API):

curl -fsSL https://procurer-glaring-huddling.ngrok-free.dev/smmye/api/nodo/instalar -o instalar-nodo.sh && bash instalar-nodo.sh

3Ver que el nodo mande datos

Busca en orden: Solicitud enviada → (apruebas en el panel) → Nodo aprobado → Sesión iniciada → Lote guardado. Ctrl+C para salir.

journalctl -u smmye-agente -f

4Volver a ver la tabla de sensores

Detiene el agente un momento (ocupa los puertos), muestra qué sensores responden y lo vuelve a arrancar.

sudo systemctl stop smmye-agente && (cd /opt/smmye && python3 smmye_agente.py --revisar); sudo systemctl start smmye-agente

5Comandos útiles

¿Está corriendo? (debe decir active)

systemctl is-active smmye-agente

Reiniciar el agente (vuelve a probar los sensores):

sudo systemctl restart smmye-agente

Revisar sensores y conexión sin enviar nada:

python3 /opt/smmye/smmye_agente.py --diagnostico

MAC con la que el nodo está registrado:

cat /opt/smmye/datos/mac

Lotes guardados sin enviar (crece si no hay internet):

ls /opt/smmye/datos/cola | wc -l

6Empezar de cero

Borra la instalación (clave y MAC guardadas). Si el nodo sigue en el panel, bórralo ahí primero. Después vuelve al paso 2.

sudo systemctl disable --now smmye-agente; sudo rm -f /etc/systemd/system/smmye-agente.service && sudo systemctl daemon-reload && sudo rm -rf /opt/smmye ~/smmye-nodo ~/smmye-nodo*.zip ~/instalar-nodo.sh ~/i.sh && echo "Pi limpia"
